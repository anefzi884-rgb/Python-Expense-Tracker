# Python Expense Tracker

A simple command-line application developed in Python for managing expenses.

## Features

1. Add an expense.
2. View all expenses.
3. Display the total amount.
4. Delete an expense by its number.
5. Calculate the average expense.

## Requirements

- Python 3
- Git (for version control)

## Run the application

Open a terminal in this folder and execute:

```bash
py expense_tracker.py
```

You can also use:

```bash
python expense_tracker.py
```

## Notes

- Expenses are stored in memory only.
- The list is reset when the application is closed.
- Amounts must be positive numbers.
